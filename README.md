Project Overview

This ZIP file contains the Jupyter Notebook submission for Project 1. The analysis investigates the temporal and environmental factors driving bike-sharing demand using the UCI Bike Sharing dataset. It includes data preparation, exploratory data analysis, formal statistical testing (t-test, Z-test for proportions,  correlation), and operational recommendations based on the findings.

## Included Files

* `Project1.ipynb`: The main executable notebook containing all Python code, statistical results, and Markdown explanations.
* `hour.csv`: The dataset required to run the analysis.

## How to Run the Code

This notebook is designed to be fully reproducible and "plug and play."

1. Ensure that both `Project1.ipynb` and `hour.csv` are downloaded and placed in the **exact same folder** (working directory) on your local machine.
2. Open the notebook using Jupyter Notebook, JupyterLab, or Google Colab.
3. Select **"Run All"** (or execute the cells sequentially from top to bottom). The code uses relative paths (`pd.read\\\\\\\_csv('hour.csv')`), so it will automatically find the dataset without any manual path editing.
